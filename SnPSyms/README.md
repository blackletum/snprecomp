`snp.jp.syms.toml` is N64Recomp's symbol file for this game: the function
boundaries (vram, size and name) of every code segment, one `[[section]]`
each. `snp.jp.toml` in the repo root points N64Recomp at it.

It's generated by `tools/gen_syms_toml.py` from spimdisasm's function lists
(`syms/spimdisasm/`) and n64sym's SDK names (`syms/n64sym_jp.txt`); see
BUILDING.md to regenerate it. Don't edit it by hand: corrections go in the
script's `OVERRIDES` table so they survive regeneration.
